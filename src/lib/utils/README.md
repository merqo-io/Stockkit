# src/lib/utils

General-purpose helpers (`cn` comes from `@merqo/ui/primitives`): the
codified "ledger"
hero-number type scale (`LEDGER_LG_CLASS`/`LEDGER_MD_CLASS`/`LEDGER_SM_CLASS`
— font-mono tabular-nums at three sizes, compose with `cn()` to layer a
status color on top), logging utilities.

The form label and error classes (`FORM_LABEL_CLASS`, `FORM_ERROR_CLASS`) are imported from `@merqo/ui`, not defined here.
